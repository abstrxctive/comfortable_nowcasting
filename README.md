# comfortable_nowcasting
Данная утилита позволяет просматривать данные наукастинга в удобном режиме. Основной сайт nowcast.ru часто падает, остаётся пользоваться наукастингом от meteoinfo, но он не очень удобный, его нельзя приближать и ставить на паузу. С помощью данной программы вы сможете пользоваться удобным просмотром радарных наблюдений с красивым дизайном.
